# 💰 Money Management App

A Flutter application for tracking income and expenses with AI-powered financial insights.

![App Icon](assets/unnamed_borderless.jpg)

## 📱 What is this app?

Money Management App helps you:

- **Track Income & Expenses**: Record your financial transactions with categories
- **View Analytics**: Interactive charts showing your spending patterns
- **AI Assistant**: Get personalized financial advice using Google's AI
- **Export Data**: Save your transactions to CSV files
- **Local Storage**: All data stays on your device for privacy

- **Internet**: Required for AI assistant features

## 🔑 Google AI Studio API Key Setup

To use the AI assistant feature, you need a Google AI Studio API key:

### Step 1: Get API Key

1. Go to [Google AI Studio](https://aistudio.google.com/)
2. Sign in with your Google account
3. Click "Get API Key" in the left sidebar
4. Click "Create API Key"
5. Copy the generated API key

### Step 2: Configure in App

1. Open Money Management App
2. Go to **Settings** tab
3. Paste your API key in the "AI API Key" field
4. Tap **Save**
5. The AI assistant is now ready to use!

### Step 3: Using AI Assistant

1. Go to **Analytics** tab
2. Scroll down to "Financial Assistant" section
3. Type your financial questions
4. Get personalized advice and insights

## 🚀 Quick Start

1. **Add Transactions**: Tap the "+" button to add income or expenses
2. **View Analytics**: Check the Analytics tab for spending insights
3. **Set up AI**: Follow the API key setup above for AI features
4. **Export Data**: Use Settings to export your data to CSV

## 🔒 Privacy

- All data is stored locally on your device
- No data is sent to external servers (except AI requests)
- Your financial information stays private
